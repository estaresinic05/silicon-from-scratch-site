      The engine of the CPU, executing billions of instructions per second. Adders and logic combined into one.

    7. Single Cycle CPU

    9. Floating Point Adder

    What you'll find

    Every design is built to be opened up.

    • 01 / RTL

      The design itself

      Synthesizable Verilog/SystemVerilog for the datapath, control unit, register file, ALU, and memory.

    • 02 / Testbenches

      Proof it's correct

      Self-checking verification, including lockstep comparison against an independent golden model.

    • 03 / Waveforms

      See it happen

      VCD traces that let you watch behavior cycle by cycle.

    • 04 / Programs

      What it runs

      RISC-V machine-code test programs exercising arithmetic, logic, memory, and control flow.

    • 05 / Interactive Tools

      Try it →

      Live, in-browser explorers — like the ALU datapath visualizer — that let you pick an operation and watch the active hardware light up as you go.

    Tools

    You can start for free.

    The core projects run on free, open-source tools — no licenses, no cost: Icarus Verilog for simulation and GTKWave / EPWave for inspecting waveforms. The advanced physical-design track uses the professional Cadence suite — useful to know it exists, but you don't need it to learn the fundamentals or to get started.

    Getting set up is essentially one download: the Icarus Verilog installer bundles GTKWave too, so you can simulate and inspect waveforms right away.
