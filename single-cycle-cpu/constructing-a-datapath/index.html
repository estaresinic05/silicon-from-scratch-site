    Constructing a Datapath

    We have every piece on the bench — the program counter, the instruction and data memories, the register file, and the ALU. On their own they are just boxes. Now we wire them into a single working circuit: the datapath, the path every instruction travels from fetch to finish. Add a few muxes and the right connections, and one design can run arithmetic, memory, and branch instructions alike.
